Overview

Northmark is a web application for software developers. Its product document describes a career-intelligence platform: a weekly batch pipeline turns job-market, compensation and skill-trend data into insights that help a developer decide which skills to learn, which certifications to get, and whether their pay matches the market.

The code also contains a learning part: a skill roadmap and coding lessons with an editor, a terminal and automated tests in the browser. Lessons in JavaScript and TypeScript run in WebContainers. Lessons in Go, Python, Java, Kotlin, Spring Boot and NestJS run on a separate container service.

Architecture

Decisions and features

A container service for lessons that WebContainers cannot run

WebContainers run Node.js inside the browser tab, so they cannot run a Go compiler, a JVM or a Python interpreter. For those lessons Northmark has its own container service, written in TypeScript with Fastify.

The lesson page asks the service for a session and sends the learner's Supabase token. The service verifies the token against the project's public keys, starts one container for that learner (replacing an earlier one) and returns a session with a one-time ticket for the WebSocket. Over the WebSocket the page sends file writes, run and test commands and terminal input. The service passes them to a small agent written in Go inside the container and sends the output back to the page.

Each lesson language has its own image, built on a common base image that contains the agent. The service removes a container when the learner leaves or the session is idle, and a periodic sweep removes containers that no session owns.

Insight pipeline

The product document describes a weekly batch: the model work runs once a week, and every user reads the stored output. The repository contains TypeScript scripts that load the collected data for each skill (job-posting counts, GitHub repository activity, search trends and Reddit sentiment), compute normalized scores, momentum labels and competition levels, ask a language model through OpenRouter for a structured insight per skill, and store the results in Supabase.

Lessons

A lesson page has a Monaco editor, an xterm.js terminal and a tests tab. A lesson starts from starter code, and the learner runs the tests against their own changes. Lesson content is stored as database migrations, and scripts validate each migration before it is applied.

Accounts, data and payments

Supabase holds the PostgreSQL database, authentication with Google or GitHub, and Edge Functions. Every table has row-level security, and a user can read only their own rows. A database trigger creates the user's profile row at sign-up.

Stripe Checkout handles the subscription. An Edge Function receives the Stripe webhook and updates the user's subscription status. Other Edge Functions send notification and career emails and generate a personal insight for a user.
